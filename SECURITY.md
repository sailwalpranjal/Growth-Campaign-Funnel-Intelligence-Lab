# Security policy

## Supported versions

Only the latest commit on the default branch. There are no tagged releases yet.

## Reporting a vulnerability

Please email pranjalsailwal09@gmail.com with the subject line "Funnel Intelligence Lab security". Include what you found, how to reproduce it, and the version or commit.

I will reply within a week to confirm I have seen it. This is a one-person project, so I cannot promise a fix timeline, but I will tell you where it stands. Please do not open a public issue until we have talked.

## Scope

The FastAPI backend in `backend/` and the static dashboard. The datasets are public and contain no personal data. There are no secrets in the repo; if you find one, tell me.
